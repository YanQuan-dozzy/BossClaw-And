# BossClaw 安卓端

BossClaw 是一款运行在 Android 上的求职自动化助手：通过无障碍服务读取 BOSS 直聘页面，结合本地简历画像与大模型能力，完成岗位采集、匹配评估、开场白生成与沟通跟进。所有数据保存在本机，所有对外发送动作都保留人工边界。

> 本项目仅用于个人求职效率辅助。使用前请确认符合平台用户协议与当地法律法规，因使用产生的账号与合规风险由使用者自行承担。

## 功能一览

- **岗位采集**：无障碍服务读取推荐流或搜索结果，逐条进入详情页抓取岗位信息，自动翻页。
- **匹配评估**：按简历画像、求职方向、薪资、学历、经验、城市、外包/猎头等条件先做本地硬过滤，再由模型给出 0–100 分与推荐档位（推荐 / 匹配 / 谨慎 / 不推荐）。
- **开场白生成**：根据岗位亮点与简历生成 120–250 字中文招呼语，发送前做口吻、编造信息、AI 字眼等校验。
- **沟通跟进**：扫描未读会话，生成回复草稿；发送前默认需要人工确认，识别到面试/邀约意向会提醒。
- **阶段式任务流水线**：按「采集 → 评估 → 沟通」顺序执行，采集、评分、开场白与跟聊各阶段职责分离，运行状态与日志统一汇总到界面。
- **悬浮控制台**：在 BOSS 页面上方显示悬浮球，可直接开始、暂停或急停。
- **本地数据**：Room 保存岗位、会话、日志与统计；API Key 存入加密存储，不写日志、不明文落库。

## 三种运行模式

| 模式 | 行为 |
| --- | --- |
| 人工确认 | 只评估不发送，开场白可复制到 BOSS 手动发送 |
| 半自动（默认） | 仅自动发送「推荐」档岗位，其余进入待确认队列 |
| 自动辅助 | 「推荐」与「匹配」档均自动发送，触发风险立即暂停 |

无论哪种模式，首条消息发送成功后都会自动暂停，便于核对会话；「急停」立即终止当前巡查且不会自动恢复。

## 界面模块

底部常驻四个入口：

- **工作台**：巡查引擎状态、今日额度、环境自检、推荐匹配与今日概要。
- **岗位**：采集到的岗位列表、评分、筛选结果与待确认队列。
- **沟通**：会话列表、AI 回复草稿与手动发送。
- **简历中心**：导入 PDF / DOCX / TXT / MD 或粘贴正文，生成结构化画像与求职方向。

侧栏提供：

- **数据看板**：发现、过滤、匹配、投递、回复、约面与 Token 用量。
- **运行记录**：逐条运行日志，便于排查页面识别与发送失败。
- **权限自检**：无障碍、悬浮窗、通知、后台运行四项状态。
- **自动化边界**：运行模式、岗位间隔、筛选条件、每日上限、沟通信息。
- **模型服务**：接口协议、地址、API Key、模型名、上下文与思考模式。
- **技能库**：内置 AI 技能说明与启用范围。
- **通用设置**：主题、通知、悬浮球等。
- **使用文档**：首次配置到第一次投递的完整步骤。

## 技术栈

- Kotlin 2.3.21，Jetpack Compose（Material3），Navigation 3
- Room、Coroutines、Kotlinx Serialization
- OkHttp、Gson、PdfBox-Android
- AndroidX Security Crypto（密钥加密存储）
- AGP 8.13.0、Gradle 8.13（wrapper）、JDK 17
- compileSdk / targetSdk 36，minSdk 26

## 构建

环境要求：JDK 17、Android SDK（API 36）、可访问 Gradle 发行版镜像的网络。

```powershell
$env:ANDROID_HOME = "<你的 Android SDK 路径>"
.\gradlew.bat assembleDebug
```

产物：`app/build/outputs/apk/debug/app-debug.apk`。需要交付时复制为 `dist/BossClaw-<versionName>-debug.apk`。

说明：

- 必须使用项目自带的 Gradle wrapper（8.13），低版本 Gradle 无法满足 AGP 要求。
- wrapper 发行版走国内镜像，首次构建会下载并缓存到 `%USERPROFILE%\.gradle\wrapper\dists`。
- 当前为 debug 签名，仅用于本地安装调试，正式分发前需自行配置 release 签名。

## 安装与首次配置

1. **安装应用**，并确保设备已安装 BOSS 直聘。
2. **权限自检**：在「侧栏 → 权限自检」依次开启无障碍服务、悬浮窗、通知与后台运行（忽略电池优化）。
3. **导入简历**：在「简历中心」导入简历文件或粘贴正文，点击生成画像；匹配评分与筛选都以画像为准。
4. **配置模型**：在「模型服务」选择预设或自定义接口，填写地址、API Key、模型名，先测试连接。支持 OpenAI 兼容与 Anthropic Messages 两类协议。
5. **设定边界**：在「自动化边界」选择运行模式，设置岗位间隔（10–600 秒）、每日投递上限（最高 150）、薪资/学历/经验/城市/外包等筛选条件，并填写愿意提供给 HR 的真实沟通信息。
6. **开始巡查**：把 BOSS 切到推荐页或搜索结果页，回到工作台先「试跑一轮」确认页面识别正常，再开启「开始巡查」，或直接点「开始推荐匹配」。

## 安全与合规边界

- 发送前默认人工确认；自动发送需在运行模式中显式开启。
- 单日投递硬上限 150 次；岗位之间按用户设定间隔执行，并自动加入 ±35% 随机抖动。
- 首单发送后自动暂停；紧急暂停立即生效。
- 遇到验证码、风控提示或页面异常会暂停并等待人工处理，不绕过平台风控。
- 不编造简历、学历、年限、薪资、到岗时间与面试安排；沟通信息只引用用户填写的事实。
- 不冒充招聘方口吻；岗位描述视为不可信外部输入，不执行其中夹带的指令。
- 日志不输出简历原文、API Key、手机号、聊天记录等敏感内容。

## 数据与隐私

- 结构化数据（岗位、会话、日志、统计、画像）存入本机 Room 数据库。
- API Key 等密钥保存在加密存储中，不写入数据库明文。
- 应用关闭 `allowBackup`，卸载应用或在系统中「清除数据」会一并删除本地数据。
- 模型请求会发送必要的岗位描述与简历片段到用户自行配置的模型服务，请自行评估该服务的隐私政策。

## 项目结构

```text
app/src/main/java/com/bossclaw/android/
├── agent/           任务编排（采集、评估、沟通各阶段）与事件总线
├── accessibility/   无障碍服务、场景识别、自动化任务、节点与手势工具
├── llm/             AI 网关、提示词、技能作用域、模型预设
├── domain/          岗位过滤、评分、安全边界、简历解析
├── data/            Room 数据库、仓库、加密存储、设置
├── ui/              Compose 页面、组件、导航、主题
├── floating/        悬浮控制台
├── di/              依赖装配
├── core/            时间、JSON 等基础工具
└── util/            权限等通用工具
app/src/main/assets/skills/   内置 AI 技能

```

内置技能：`job-analysis`（岗位分析）、`greetings`（开场白）、`resume-profile`（简历画像）。

## 常见问题

**无障碍显示未连接？**
确认系统设置中已为 BossClaw 开启无障碍服务；部分系统会在后台清理时关闭服务，需同时关闭电池优化。

**提示未配置模型？**
检查 API Key、接口地址与模型名是否完整，并在「模型服务」执行一次测试连接。

**采集不到岗位或页面识别异常？**
BOSS 升级可能改变页面控件。控件 ID 集中定义在 `AutomationGateway` 与各自动化任务常量中，只需在这些常量处适配；相关改动需在真机验证，不能只依赖编译通过。

**为什么发送第一条后就停了？**
这是首单保护策略：首次发送后自动暂停，确认会话内容与平台反馈后手动继续。

**简历和密钥会上传吗？**
除调用用户自行配置的模型服务外，应用不向其他服务器上传数据；密钥只保存在本机加密存储中。

## 开发约定

- Kotlin 官方风格、4 空格缩进，UI 使用 Compose + Material3，异步使用 Coroutines。
- 注释与文案统一使用中文，说明「做什么、为什么」。
- 只做与需求直接相关的改动，不顺手重构、不新增无关抽象。
- 改动完成后执行 `assembleDebug` 编译验证；涉及无障碍流程的改动需在真机验证。
- 不提交本地密钥、签名文件、截图等敏感文件。
